# Hono Sqids API

This Node.js ESM example imports the published @mdhthahmd/sqids@2.0.0 package.

Run pnpm --filter @sqids-examples/hono-api build and pnpm --filter @sqids-examples/hono-api start.

The API provides number and BigInt encode/decode routes below /sqids. BigInts are accepted and returned as decimal strings so all responses remain valid JSON.
